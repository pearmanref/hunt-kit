Five questions

Q1 · What is running that should not be?pslist vs psscan · pstree parentage · cmdline · malfind · unsigned or user-writable path
Q2 · What is talking that should not be?netscan / sockstat · session vs the process's job · fixed-interval beacons · same IP on both hosts · DNS cache, hosts file
Q3 · How does it survive a reboot?services, tasks, Run keys, WMI · cron, enabled systemd, rc, ld.so.preload, authorized_keys · target = the Q1 file
Q4 · Who did it, and how did they get in?4624 type 3/10, 4648, 4672 · auth.log, last/lastb, UID 0 · a web request with no matching auth is the answer
Q5 · When did it start?Prefetch, Amcache, UserAssist, BAM before file times · $SI vs $FN · fls + mactime vs access/auth logs

Decision gates

  1. G1 Unsigned / writable path / bad parent → acquire + hash the file
  2. G2 External session, no business reason → bind to a process and a log
  3. G3 Persistence targets that file → foothold confirmed
  4. G4 Account + auth method found → extend scope to other hosts
  5. G5 First-seen before the alert → intrusion start

Rules

  • Acquire before alter. Memory first, hashed.
  • Two independent sources or it is a lead, not a finding.
  • State the reasoning: expected result before, what changed after.
  • Breadth first: Q1–Q5 shallow on both hosts before depth.

Confidence

  • Possible: one source, a lead
  • Probable: consistent, partly corroborated
  • Confirmed: two independent sources agree

Time

  • Record UTC. Volatility = UTC. PowerShell, Event Viewer, ls, syslog = host local. Apache carries its own offset.
